## NPC research decision

The owner selected native mannequins for all 24 elves, workshop Santa and big-tree Santa. This is the 2026 setup policy; Citizens remains an optional supported integration but is not selected for these characters.

The supported Paper 26.3 Mannequin API provides profile/skin appearance, worn equipment, immovability and supported entity poses. Native scale, pose, profile and equipment behavior was checked in the build-823 local probe; final character placement and Java/Bedrock visual review remain pending. This is a strong default for stationary elves and Santa without adding Citizens as a hard dependency. Use `Mannequin.validPoses()` and fail validation for unsupported poses; arbitrary arm/leg articulation is not promised by this API.

An optional Citizens adapter is appropriate for existing staff-managed NPCs, NPC traits or richer behaviors. The installed source is Citizens 2.0.44-SNAPSHOT build 4255. Bind `NPC#getUniqueId()` and handle `NPCRightClickEvent`; numeric IDs are not guaranteed globally unique across sessions, and the client/entity UUID is not the persistent NPC UUID. Skin and visual selections remain for the owner. See the [API evidence](../compatibility-tests/advent-26.3-2026-10-28.md).

## Missing Mitten implementation and relocation

Missing Mitten is implemented independently of daily Advent progress, community contributions and perfect-24 eligibility. Each player starts with the dedicated elf, right-clicks the fixed shared hidden mitten, and returns to the same elf UUID. Discovery is virtual, with no inventory item. Durable not-started/searching/found/completed stages survive reconnects and restarts. Completion immediately awards the cosmetic Mitten Finder passport badge once per season. The launch command-extra configuration remains disabled.

The optional command-extra hook is implemented for a later explicitly selected prize, with a separate frozen entitlement and receipt claimed from any world before January 1. Known CMI/LuckPerms deliveries require provider verification; LuckPerms always uses the actual server UUID, including Floodgate identities. Generic uncertain outcomes require recorded staff evidence and are never blindly replayed. Enabling a prize later does not retroactively grant it to already completed quests. This support does not lift the extra-home hold.

Staff initially spawn/bind the quest elf near arrival, then may use `/advent admin move <id>` to relocate that loaded native mannequin to their current Santa position. The helper validates actor identity/persistence, same world, finite in-height destination, already-loaded target chunk and absence of passengers/vehicles. It uses the supported teleport API, verifies the result, preserves UUID/appearance/progress and invalidates old interaction authority. Position persists with normal world saving; no unbind/respawn or progress reset occurs. Citizens and the composite mitten sculpture are excluded from this move command. Final placement and human quest-flow acceptance remain on the checklist above.
