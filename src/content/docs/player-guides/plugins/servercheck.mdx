This page introduces ServerCheck as a public staff guide. It focuses on what the tool does, how authorized staff get started, and which commands are useful.

## What It Does

Review the Java, Paper, CMI, and CMILib runtime, check plugin dependencies, and run post-update diagnostics.

## How Staff Use It

ServerCheck gives staff one place to check installed plugin versions, review startup and Paper diagnostics, and run post-update smoke tests.

Available features include:

- A searchable inventory of loaded plugins, versions, enabled state, and curated project links.
- Declared dependency reports with required and optional dependents, indirect required chains, aliases, and load-order references.
- A tested Java, Paper, CMI, CMILib, and dependency compatibility gate.
- Plugin and server summaries for post-update support checks.
- A persistent plugin inventory database with optional refresh behavior.
- Manual source, download, documentation, and support URL curation.
- URL audits that highlight missing or malformed project links.
- Full Markdown and compact Discord-friendly export reports.
- Startup, folder, and read-only Paper safety diagnostics.
- Explicit post-update smoke checks for commands, placeholders, integrations, and version compatibility.

## Quick Start

1. Use `/servercheck status` to see the runtime and module states.
2. Follow the [ServerCheck staff reference](/staff-reference/plugins/servercheck/) for permissions, command examples, and upgrade steps.
